# Task 1 — Amazon S3 Bucket

## Objective

Create an Amazon S3 bucket, upload a file, document the process, and provide screenshots as evidence.

## Steps Completed

### 1. Created an S3 Bucket

I opened the AWS Management Console and navigated to Amazon S3.

I created a new S3 bucket with a globally unique bucket name.

The default security settings were maintained:

* ACLs disabled
* Block all public access enabled

### 2. Created a Test File

I created a test file named `s3-test.txt` containing:

```text
Hello from my AWS S3 assignment
```

### 3. Uploaded the File

I opened the S3 bucket and selected **Upload**.

I uploaded:

`s3-test.txt`

The file was successfully uploaded and appeared in the S3 bucket.

The S3 bucket was successfully created and the test file was successfully uploaded.
