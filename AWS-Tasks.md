# AWS Practical Tasks

> **Prerequisite:** Clone the repository to your local machine before starting the tasks.

1. Create a bucket, upload a file, document your steps and screenshot and upload it on GitHub.

2. Host a static website using the coffee shop folder, document your steps and screenshot and upload it on GitHub.

3. Create a VPC, with 2 subnets, internet gateway, route table. Launch an EC2 in each subnet, install nginx in each EC2 and load the nginx default page in your browser, document your steps and screenshot and upload it on GitHub.
